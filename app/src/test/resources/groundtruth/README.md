# Ground-truth files

One JSON file per reference video: the solves it should give. The videos themselves stay on the phone and are never committed.
Format, how to make one, and the baseline table: [docs/algorithms.md § 8](../../../../../docs/algorithms.md#ground-truth-harness-33-a).
`SolveAnalyzerScanTest.groundTruthFiles_areValid` checks every `.json` file here.
